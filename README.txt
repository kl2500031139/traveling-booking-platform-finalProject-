Wayfare - Travel Booking Platform
=================================
Keep all files in the same folder and open index.html in any browser.
No server needed.

Pages
  index.html          Home: browse trips, trip details and booking,
                      My bookings (user), Admin dashboard (admin)
  login.html          Traveller login
  register.html       Traveller sign up
  admin-login.html    Admin login (separate page)
  style.css           Styling (light + dark mode)
  app.js              Shared logic: login, booking, admin, localStorage
  standalone-single-file.html   Whole app in one file (alternative)

Demo logins
  Traveller: user@wayfare.com  / user123    (login.html)
  Admin:     admin@wayfare.com / admin123   (admin-login.html)

Data is stored in your browser's localStorage only.
Use "Reset demo data" in the admin dashboard to restore the starting data.
